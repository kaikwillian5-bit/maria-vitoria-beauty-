Como a mensagem é enviada pela API oficial do WhatsApp, o texto precisa ser um modelo (template) aprovado pela Meta — não dá para editar por aqui na hora.

Para mudar o texto: crie um novo modelo no WhatsApp Manager (Meta Business Suite), aguarde a aprovação, e depois atualize o nome dele no arquivo .env do backend (variável WHATSAPP_TEMPLATE_CONFIRMACAO).
